# CONQUEST — магазин швейцарских часов

Статический магазин на три страницы, свёрстанный по макету Figma: главная, каталог
мужских часов, карточка товара. Astro, статическая сборка, Yarn.

## Что внутри

| Слой       | Что именно                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Страницы   | главная, каталог, карточка товара, двенадцать разделов подвала и шапки, 404                                                                                                                 |
| Секции     | промо, популярные модели, баннер качества, новости, фильтр, сетка, ремешки, галерея, просмотренное                                                                                          |
| Модули     | `gsap.ts`, `reveal.ts`, `parallax.ts`, `menu.ts`, `sweep.ts`, `stroke.ts`, `tilt.ts`, `carousel.ts`, `gallery.ts`, `tabs.ts`, `price-range.ts`, `bag.ts`, `search.ts`, `sort.ts`, `drop.ts` |
| Компоненты | `button`, `price`, `logo`, `breadcrumbs`, `product-card`, `showcase-card`, `strip`, `carousel`, `shop-bar`, `seo`                                                                           |
| Стили      | `reset.css`, измеренные токены, контейнер и вертикальный ритм                                                                                                                               |
| Тесты      | шапка, меню, каталог, карточка, разделы и целостность ссылок, страховки движения, состояние магазина                                                                                        |

Формы на страницах нет: макет её не рисует ни на одной из трёх. Модуль формы с
маской телефона остался в доноре — адрес в `docs/donors.md`.

## Макет

Один файл Figma, три фрейма по 1366. Ключ файла, карта узлов по секциям и порядок
чтения — `docs/figma.md`. Узких раскладок в макете нет: мобильная и планшетная
выведены из десктопных замеров, вывод — `docs/adr/0006-responsive-steps.md`.

## Команды

```
yarn dev            # дев-сервер на 4321
yarn build          # astro check && astro build
yarn preview        # просмотр сборки
yarn lint           # ESLint
yarn lint:styles    # Stylelint
yarn format         # Prettier
yarn test:browser   # Playwright: собирает и поднимает просмотр на 4331
```

**Только Yarn.** `npm install` при наличии `yarn.lock` перепишет его под себя и
сломает установку у коллег на других платформах.

Сборка тянет три гарнитуры (Playfair Display, Prata, Roboto) через провайдер
`astro:assets` и кладёт их в сборку локально. Первая сборка требует сети; дальше
файлы берутся из кеша Astro.

## Чего не хватает до прода

- **Домен.** `site` в `astro.config.mjs` и адрес карты сайта в `public/robots.txt`
  выведены из почты магазина в макете (`info@conquest.watch.ru`). Настоящий домен
  заменяет оба места.
- **Проверка текста восьми разделов.** `/payment/`, `/warranty/`, `/returns/` и
  `/corporate/` содержат условия сделки, написанные не владельцем: макет их только
  называл. До прода он обязан их прочитать — разбор
  `docs/adr/0011-sections-without-frames.md`.
- **Серверная часть.** Избранное и корзина держатся в `localStorage` этого
  браузера, поиск и сортировка считаются на клиенте по реестру
  `src/data/products.ts`, фильтр ничего не отправляет. Заказ, оплата и живой
  каталог — за сервером; точка врезки одна, реестр
  (`docs/adr/0012-shop-state.md`).
- **Три ответа владельца** по содержимому фильтров и панели характеристик — там же,
  в «Не выяснено».
