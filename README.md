# Шаблон лендинга

Донорский репозиторий, из которого заводятся лендинги. Astro, статика, Yarn,
выстроенный тулинг и набор правил, выведенных на живых страницах, а не придуманных.

Шаблон **собирается, проходит линт, типы и браузерные тесты сразу после
`yarn install`.** Если что-то из этого падает — чинить надо шаблон, а не обходить в
проекте.

## Что внутри

| Слой       | Что именно                                                                            |
| ---------- | ------------------------------------------------------------------------------------- |
| Тулинг     | ESLint 10 с обходами, Stylelint, Prettier, husky + lint-staged, Playwright, Astro     |
| Модули     | `gsap.ts`, `reveal.ts`, `parallax.ts`, `phone-mask.ts`, `request-form.ts`, `menu.ts`  |
| Компоненты | `button`, `input`, `seo`, `header`, `footer` и три демонстрационные секции            |
| Стили      | `reset.css`, служебные токены, контейнер и вертикальный ритм                          |
| Документы  | `CLAUDE.md`, `CONTEXT.md`, пять ADR, `figma.md`, `tests.md`, `deploy.md`, `donors.md` |
| Тесты      | якоря шапки, мобильное меню, маска и валидация формы                                  |

Чего внутри нет намеренно: сцен со скролл-триггерами, вкладок, каруселей, лент и
прочего, что заказывается макетом поимённо. Всё это уже написано в соседних
лендингах — адреса в `docs/donors.md`.

## Как завести новый лендинг

```
cp -r template ../<имя>        # или degit, если шаблон уедет на GitHub
cd ../<имя>
rm -rf .git dist node_modules
git init -b main
yarn install
```

Дальше — замены. Список короткий, но каждая строка обязательна: пропущенная уезжает
в прод.

| Где                           | Что заменить                                                 |
| ----------------------------- | ------------------------------------------------------------ |
| `package.json`                | `name`                                                       |
| `astro.config.mjs`            | `site` — пока домена нет, оставить `https://example.invalid` |
| `public/robots.txt`           | адрес карты сайта                                            |
| `src/components/seo.astro`    | `SITE_NAME`, поля `ORGANIZATION`                             |
| `src/pages/index.astro`       | `title`, `description`                                       |
| `src/pages/privacy.astro`     | `title`, `description`, текст политики                       |
| `src/components/header.astro` | логотип и список якорей                                      |
| `src/components/footer.astro` | контакты и копирайт                                          |
| `public/favicon.svg`          | знак продукта                                                |
| `public/og-image.png`         | превью 1200×630 — файла в шаблоне нет, его надо положить     |
| `CONTEXT.md`                  | имя продукта, глоссарий                                      |
| `CLAUDE.md`                   | шапка файла и шаблонные оговорки — см. первый абзац там      |
| `docs/figma.md`               | ключ файла макета и карта узлов                              |

Первая задача по вёрстке — шапка и промо: на них проверяются токены, шрифт и сетка.
Она же снимает с проекта два чужих числа — `--layout-width` и `--layout-gutter`,
приехавшие из чужого макета, — и заменяет служебную серую палитру измеренной.

Демонстрационные секции `sample.astro` и `request.astro` удаляются, когда появляется
настоящая вёрстка; `request.astro` — вместе с переносом формы в ту секцию, где она
нарисована.

## Команды

```
yarn dev            # дев-сервер на 4321
yarn build          # astro check && astro build
yarn preview        # просмотр сборки
yarn lint           # ESLint
yarn lint:styles    # Stylelint
yarn format         # Prettier
yarn test:browser   # Playwright: собирает и поднимает просмотр на 4331
```

**Только Yarn.** `npm install` при наличии `yarn.lock` перепишет его под себя и
сломает установку у коллег на других платформах — разбор в `CLAUDE.md`.

## Как шаблон меняется

Правка приезжает сюда из проекта, а не наоборот: что-то понадобилось второму
лендингу подряд — значит, место ему в шаблоне. Обратного потока нет, шаблон в чужие
репозитории ничего не досылает.

Разбор, из которого шаблон вырос, — `.scratch/bootstrap/PRD.md`.
