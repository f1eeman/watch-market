# Модули с контрактом в разметке: атрибуты

Каждый модуль включается атрибутом. Разметка объявляет намерение, числа живут в
модуле, причины — в ADR. Классы модули не читают: вёрстка пишется заново под каждый
макет, а `data-*` переезжают без правок.

Файл назывался `animation-modules.md`, пока модулей было два и оба двигали блоки.
С каруселью, галереей, вкладками и слайдером половина списка к анимации не
относится, поэтому имя расширено.

## Движение по прокрутке

Точка входа одна — `src/scripts/gsap.ts`: там регистрируется `ScrollTrigger` и живёт
общий `gsap.matchMedia()`. Всё, что двигается по прокрутке, оборачивается в него,
чтобы `prefers-reduced-motion` соблюдался автоматически.

### `reveal.ts` — появление по прокрутке

Числа и пороги — `docs/adr/0002-mobile-section-reveal.md`.

| Атрибут               | Значение                                             | Что делает                                                                             |
| --------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `data-reveal`         | `up` (по умолчанию), `down`, `left`, `right`, `fade` | Блок выезжает в указанном направлении по своему гейту                                  |
| `data-reveal-stagger` | число секунд, пусто — `0.12`                         | Выше `DESKTOP` едут прямые дети с задержкой, гейт на блоке; ниже — у каждого свой гейт |
| `data-reveal-each`    | без значения                                         | У каждого прямого ребёнка свой гейт; ритм задаёт скролл, а не `stagger`                |
| `data-reveal-start`   | строка `ScrollTrigger`                               | Свой порог вместо базового — блокам, которые до базового не доезжают                   |
| `data-reveal-below`   | ширина в px                                          | Модуль работает только ниже этой ширины; выше свойством распоряжается сцена            |

`autoAlpha` и `y` на двоих не делятся: если блоком занялась сцена, `data-reveal`
с него снимается или ограничивается `data-reveal-below`.

**Блок, уже стоящий в кадре, модуль не трогает.** Раньше такой блок отдёргивался
назад на 128 точек и въезжал заново — рывок, который владелец увидел при переходах
между страницами: на узкой раскладке под сгиб попадают и плитки популярных, и
сетка каталога, а порог `ScrollTrigger` они проходят в том же кадре. Проверка
`inFrame()` сравнивает верх блока с высотой окна и в этом случае выходит, оставляя
блок видимым. Гейта у блока после этого нет — и не нужен: он уже на экране.

### `parallax.ts` — дрейф слоёв по прокрутке

Работает от 1024px и только под `no-preference`. Числа и амплитуды —
`docs/adr/0009-motion-scenes.md`.

| Атрибут                | Значение                | Что делает                                            |
| ---------------------- | ----------------------- | ----------------------------------------------------- |
| `data-parallax`        | доля, пусто — `0.3`     | Слой смещается на долю своей высоты за проезд сцены   |
| `data-parallax-rotate` | градусы                 | Слой доворачивается от макетного состояния            |
| `data-parallax-scale`  | масштаб начала          | Слой садится из этого масштаба **в** макетный         |
| `data-parallax-scene`  | без значения, на предке | Задаёт сцену — отрезок прокрутки, за который идёт ход |

Хватит любого из трёх первых атрибутов: модуль забирает элемент, если стоит хотя бы
один. Без `data-parallax-scene` сценой считается родитель слоя.

`y` и `rotate` уводят слой **от** макетного состояния, `scale` приводит **к** нему —
иначе фото пришлось бы рисовать в макете уже увеличенным.

### `sweep.ts` — пословный разворот заголовка

Разборы — `docs/adr/0009-motion-scenes.md` и `docs/adr/0010-motion-plugins.md`. Такт
импортируется из `reveal.ts`, своего у модуля нет.

| Атрибут           | Где                 | Что делает                                  |
| ----------------- | ------------------- | ------------------------------------------- |
| `data-sweep`      | заголовок с текстом | Слова выезжают из-под своих кромок каскадом |
| `data-sweep-line` | линия-подчёркивание | Прочерчивается от левого края               |

Текст лежит в заголовке как есть — обёртки строит `SplitText` (`mask: 'words'`), он
же кладёт всю фразу в `aria-label` и пересчитывает разбиение по загрузке шрифта.
Слова получают класс `sweep-word` — по нему их находит страховочный тест.

Запас под выносные элементы держит `global.css`: `overflow: hidden` плюс
`padding-block-end: 0.25em` с компенсацией отрицательным полем.

### `stroke.ts` — обводка прочерчивается

Разбор — `docs/adr/0010-motion-plugins.md`.

| Атрибут             | Где                  | Что делает                               |
| ------------------- | -------------------- | ---------------------------------------- |
| `data-stroke`       | `<circle>`, `<path>` | Обводка рисуется от нуля до полной длины |
| `data-stroke-scene` | предок               | Что должно войти в кадр, чтобы начать    |

Работает только по настоящей SVG-геометрии: `div` с маской, изображающий обводку,
прочертить нечем. Без `data-stroke-scene` триггером становится сам путь.

### `tilt.ts` — наклон под курсором

Разбор — `docs/adr/0010-motion-plugins.md`. Работает от 1024px, только при
`hover: hover` и `pointer: fine` и только под `no-preference`.

| Атрибут     | Где                         | Что делает                                      |
| ----------- | --------------------------- | ----------------------------------------------- |
| `data-tilt` | корень интерактивной плитки | Плитка поворачивается в перспективе за курсором |

Максимум 6°, один твин на кадр. Уборка при уходе за порог снимает слушатели и
чистит свойства.

## Вход первого экрана — на каскаде, без модуля

Блоки выше сгиба анимировать `gsap.from()` нельзя: модуль приезжает после первой
отрисовки и блок отдёргивается назад. Поэтому вход — `@keyframes` в `global.css`
внутри `@media (prefers-reduced-motion: no-preference)`; JS в нём не участвует
вовсе.

| Атрибут             | Значение               | Что делает                           |
| ------------------- | ---------------------- | ------------------------------------ |
| `data-enter`        | пусто — подъём на 48px | Блок въезжает снизу с проявлением    |
| `data-enter="fade"` | —                      | Только проявление                    |
| `data-enter="draw"` | —                      | Прочерк от левого края — для засечек |
| `data-enter="lift"` | —                      | Подъём на 64px с осадкой масштаба    |
| `data-enter-step`   | `1`…`7`                | Ступень каскада, 70мс на шаг         |

Ставится **только выше сгиба** — на промо, крошки, `h1`, сортировку каталога,
галерею и инфо-блок карточки. Ниже сгиба тем же занимаются `reveal.ts` и
`sweep.ts`; двойной источник на одном элементе запрещён.

## Взаимодействие

Ни один модуль ниже не трогает GSAP: всё, что им нужно, каскад и платформа умеют
сами.

### `menu.ts` — бургер с гармошкой

Разбор — `docs/adr/0001-button-microinteractions.md` (такт и тач-цели). Гармошка
работает и без скрипта: `<details>` открывается сам.

| Атрибут                 | Где                | Что делает                               |
| ----------------------- | ------------------ | ---------------------------------------- |
| `data-menu`             | `<details>`        | Корень; по нему модуль находит остальное |
| `data-menu-toggle`      | `<summary>`        | Возврат фокуса после Esc                 |
| `data-menu-label`       | внутри `<summary>` | Текст, который модуль подменяет          |
| `data-menu-label-open`  | на `<summary>`     | Доступное имя в закрытом состоянии       |
| `data-menu-label-close` | на `<summary>`     | Доступное имя в открытом состоянии       |

Модуль добавляет четыре вещи: Esc с возвратом фокуса, закрытие по клику на ссылку,
закрытие по клику мимо и смену доступного имени.

### `carousel.ts` — ряд с прилипанием и стрелками

Разбор — `docs/adr/0007-carousel-and-gallery.md`.

| Атрибут                | Где                | Что делает                                             |
| ---------------------- | ------------------ | ------------------------------------------------------ |
| `data-carousel`        | корень             | По нему модуль находит остальное                       |
| `data-carousel-track`  | прокручиваемый ряд | Обязателен; без него модуль на этом корне не заводится |
| `data-carousel-prev`   | `<button>`         | Шаг назад на один шаг ряда                             |
| `data-carousel-next`   | `<button>`         | Шаг вперёд                                             |
| `data-carousel-status` | элемент с текстом  | Номер текущего элемента, `01`-формат                   |
| `data-carousel-still`  | ставит модуль      | Прокручивать нечего; крючок для CSS                    |

Шаг — расстояние между левыми краями первых двух детей, замеряется в момент клика.
Кнопки гасятся `disabled` по замеру прокручиваемой ширины, а не по счётчику.

### `gallery.ts` — выбор кадра

Разбор — `docs/adr/0007-carousel-and-gallery.md`.

| Атрибут                | Где           | Что делает                                  |
| ---------------------- | ------------- | ------------------------------------------- |
| `data-gallery`         | корень        | По нему модуль находит остальное            |
| `data-gallery-slide`   | кадры стопкой | Кадров и миниатюр обязано быть равное число |
| `data-gallery-thumb`   | `<button>`    | Выбор кадра по своему порядковому номеру    |
| `data-gallery-prev`    | `<button>`    | Предыдущий кадр, с последнего — на первый   |
| `data-gallery-next`    | `<button>`    | Следующий кадр, с первого — на последний    |
| `data-gallery-current` | ставит модуль | Текущий кадр; крючок для CSS                |
| `data-gallery-flip`    | ставит модуль | Идёт перелёт; крючок, гасящий кроссфейд     |

Активная миниатюра помечается `aria-current="true"` — тем же атрибутом, что читает
скринридер, а не своим классом. Кадров меньше двух — модуль не заводится.

Под `no-preference` клик по миниатюре запускает перелёт кадра из неё (`Flip`); по
стрелкам остаётся кроссфейд — у них нет исходного прямоугольника. Разбор —
`docs/adr/0010-motion-plugins.md`.

### `tabs.ts` — вкладки с панелями

Разбор — `docs/adr/0008-catalog-controls.md`.

| Атрибут            | Где                     | Что делает                                         |
| ------------------ | ----------------------- | -------------------------------------------------- |
| `data-tabs`        | корень                  | По нему модуль находит остальное                   |
| `data-tabs-tab`    | `<button role="tab">`   | Вкладок обязано быть столько же, сколько панелей   |
| `data-tabs-panel`  | `<div role="tabpanel">` | Скрывается атрибутом `hidden`                      |
| `data-tabs-marker` | пустой `<span>`         | Линия под активной вкладкой; переезжает между ними |
| `data-tabs-panels` | обёртка панелей         | Её высоту модуль ведёт при смене панели            |

Модуль ведёт `aria-selected`, `tabindex` и `hidden`; стрелки, `Home` и `End`
переводят фокус вслед за выбором. Нажатие по уже открытой вкладке не
перепроигрывает появление — фокус при этом всё равно переводится.

Линия обязана лежать прямым ребёнком своего списка: модуль пишет `--marker-x`,
`--marker-y` и `--marker-size` в родителя маркера и туда же вешает
`ResizeObserver`. Разметка без `data-tabs-marker` и `data-tabs-panels` работает —
вкладки переключаются мгновенно, без линии и без хода высоты.

### `price-range.ts` — двуручьевой слайдер

Разбор — `docs/adr/0008-catalog-controls.md`.

| Атрибут               | Где                    | Что делает                                       |
| --------------------- | ---------------------- | ------------------------------------------------ |
| `data-range`          | корень                 | На него модуль пишет `--range-from`/`--range-to` |
| `data-range-track`    | дорожка                | От неё считается доля при выборе ближней ручки   |
| `data-range-from`     | `<input type="range">` | Левая ручка                                      |
| `data-range-to`       | `<input type="range">` | Правая ручка                                     |
| `data-range-from-out` | элемент с текстом      | Подпись левой ручки                              |
| `data-range-to-out`   | элемент с текстом      | Подпись правой ручки                             |

Границы и шаг берутся из `min`/`max`/`step` самих полей — в модуле их нет. Ручки не
перехлёстываются: та, что зашла за соседнюю, приравнивается к ней. Разряды в
подписи разделяет неразрывный пробел.

Поля лежат друг на друге, и наверх модуль поднимает то, до чьей ручки курсору
ближе, — `z-index`, а не `pointer-events`. Почему прозрачность для курсора здесь
не работает — в разборе, там же замер.

### `sort.ts` — порядок плиток в сетке

Разбор — `docs/adr/0012-shop-state.md`.

| Атрибут            | Где                | Что делает                                          |
| ------------------ | ------------------ | --------------------------------------------------- |
| `data-sort`        | `<details>`        | Значение — `id` сетки, которую модуль переставляет  |
| `data-sort-rule`   | `<button>` правила | `popular`, `cheap`, `costly`, `brand`               |
| `data-sort-label`  | там же             | Подпись, которая уезжает в `data-sort-value`        |
| `data-sort-value`  | элемент с текстом  | Показывает выбранное правило                        |
| `data-sort-amount` | `<li>` сетки       | Число для сравнения; напечатанную цену не разбираем |
| `data-sort-brand`  | `<li>` сетки       | Второй ключ сортировки                              |
| `data-sort-pin`    | `<li>` сетки       | Не участвует в сортировке и остаётся на своём месте |

Плитки переставляются, а не рисуются заново. Правило `popular` возвращает порядок
разметки, снятый при инициализации.

### `bag.ts` — избранное и корзина в `localStorage`

Разбор — `docs/adr/0012-shop-state.md`.

| Атрибут              | Где                      | Что делает                                  |
| -------------------- | ------------------------ | ------------------------------------------- |
| `data-shop-index`    | `<script type="…/json">` | Реестр `id`/бренд/цена для панелей и поиска |
| `data-bag`           | `<button>`               | `favourites` или `cart`; кладёт и убирает   |
| `data-bag-id`        | там же                   | Что именно кладём                           |
| `data-bag-label`     | внутри кнопки            | Текст состояния                             |
| `data-bag-label-on`  | на кнопке                | Подпись, когда позиция отложена             |
| `data-bag-label-off` | на кнопке                | Подпись, когда нет                          |
| `data-bag-panel`     | `<details>` в шапке      | Панель своей сумки                          |
| `data-bag-count`     | элемент с текстом        | Счётчик; при нуле уходит под `hidden`       |
| `data-bag-list`      | `<ul>`                   | Сюда модуль складывает строки               |
| `data-bag-empty`     | элемент с текстом        | Показывается, когда сумка пуста             |

Состояние кнопки — `aria-pressed`, а не свой класс. Нажатия ловятся делегированием
на документе: строки панелей создаёт сам модуль.

Видимое состояние рисует CSS по `aria-pressed`, модуль о нём не знает: парные
`.glyph-off` / `.glyph-on` внутри кнопки переключаются `display`. Так же меняется
надпись кнопки «В корзину» на карточке товара.

Панели шапки — взаимоисключающая группа `<details name="shop">`: ниже порога они
падают в одно место, во всю ширину шапки. Esc и нажатие мимо закрывают их через
`drop.ts` — общий для поиска, сортировки и сумок.

### `search.ts` — поиск по бренду и цене

Разбор — `docs/adr/0012-shop-state.md`.

| Атрибут               | Где               | Что делает                            |
| --------------------- | ----------------- | ------------------------------------- |
| `data-search`         | `<details>`       | По нему модуль находит остальное      |
| `data-search-field`   | `<input>`         | Запрос                                |
| `data-search-results` | `<ul>`            | Сюда уезжают находки, не больше шести |
| `data-search-empty`   | элемент с текстом | «Ничего не нашли»                     |

Индекс берётся из `[data-shop-index]` — того же, что читает `bag.ts`. Пробелы в
запросе и в цене вычищаются, поэтому «12 700» и «12700» находят одно и то же.

## Правило одного источника

Один источник движения — один уровень разметки. Прокрутка, курсор и собственный цикл
не делят элемент: последний записавший затирает предыдущих.

Появление вложенным тоже не бывает: ребёнок наследует трансформ родителя, и сдвиг
считается дважды.

## Чего в списке нет

Сцен со скролл-триггерами, автономных циклов и едущих лент. Базовый такт страниц —
появление секций по прокрутке плюс состояния на CSS; всё остальное заказывается
макетом поимённо и приезжает со своим разбором.
